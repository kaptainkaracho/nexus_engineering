## Quick Start

### For Users

1. Start with [ONBOARDING.md](./onboarding.md) for your first 30 minutes with Nexus
2. Use [USER_GUIDE.md](./USER_GUIDE.md) for an overview of the application
3. Use [API_REFERENCE.md](./API_REFERENCE.md) for programmatic access

### For Developers

1. Read [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md) for development setup and workflow
2. Follow [CODING_STANDARDS.md](./CODING_STANDARDS.md) for code style guidelines
3. Review [ARCHITECTURE.md](./ARCHITECTURE.md) to understand the system design
4. Check [DEPLOYMENT.md](./DEPLOYMENT.md) for deployment instructions

### For API Consumers

1. See [API_REFERENCE.md](./API_REFERENCE.md) for complete endpoint documentation
2. Use [API_CONTRACT.md](./API_CONTRACT.md) for integration contracts
3. Check [api/repository-reader-api.yaml](./api/repository-reader-api.yaml) for OpenAPI spec
